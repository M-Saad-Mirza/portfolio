# Muhammad Saad Mirza Portfolio

A modern React portfolio site for a 7th semester Computer Science student, designed to showcase skills, projects, and contact links.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to GitHub Pages with GitHub Actions

1. Push this project to a GitHub repository.
2. In GitHub, open the repository.
3. Go to Settings → Pages.
4. Under Source, choose GitHub Actions.
5. Commit and push to the `main` branch.
6. GitHub Actions will build and deploy the site automatically.

The deployment workflow is already included in `.github/workflows/deploy.yml`.

## Portfolio info
